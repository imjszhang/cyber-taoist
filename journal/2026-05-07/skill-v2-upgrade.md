## 1. 背景与动机

v1.0.0 的应用指南把宪章里的 N/R/T/EC/NI 五元拆成了一套"七步分析 + 守破二选一"的填表法。在实际套用一段时间后，暴露了三个结构性问题：

- **预测倾向**：模板里的"识天道（N）"一步容易被读者直接当成"预言天道是什么"，而不是"通过后果反推"，违背宪章第二条"天道不可直接观测"。
- **守破二元化**：第二节给了一张"守 / 破 / 预警"决策表，把守与破做成互斥选项，遮蔽了宪章里"分形结构同时守与破"的本意。
- **死亡缺位**：v1 几乎没有谈"死亡"。失败、清算、退出只是被当成负面结果，没有被当作天道反馈的最强信号，也没有"可死亡边界"的设计语言。

升级目标：把指南从"填表 + 守破选择"改写成"观变适道协议"，让使用者强制先列后果、再反推天道，并把守与破嵌入分形结构，明确哪一层可以死亡。

## 2. 分析过程

### 2.1 v1 与 v2 结构对照

| 维度 | v1.0.0 | v2.0.0 |
| ---- | ------ | ------ |
| 总章节 | 四节（框架 / 守破启发式 / 分形模板 / 应用场景） | 六节（原则 / 流程 / 阶段 / 守破 / 输出模板 / 边界） |
| 切入点 | 七步框架，第三步直接"识天道" | 五条使用原则前置，强制"不预测，只感知后果" |
| 守破 | 二选一决策表（守 / 破 / 预警） | 分形守破：核心 / 缓冲 / 探针三层并行 |
| 死亡 | 不出现 | 单列"可死亡边界"与"死亡反馈"两节 |
| 主体层级 | 微观 / 中观 / 宏观（按物理尺度） | 个体 / 组织 / 生态（按分形角色） |
| 输出形态 | 一张"分形分析模板"表 | 八段式 markdown 输出模板 |
| 应用示例 | 四个场景（职业 / 创业 / 历史 / 道德经） | 全部删除，避免示例化思维替代分析 |

### 2.2 关键转向

- **从"识"到"反推"**：第 3 步措辞由"识天道（N）"改为"反推自然（N）"，并要求每个反推结论附带反证条件（"出现什么后果，说明这个判断可能错了？"）。
- **法则三层化**：v1 的法则（R）是一个口袋概念；v2 拆为显性规则 / 隐性惯例 / 技术范式，避免把"书面规则"当成"实际规则"。
- **生态位 ≠ 安全显式化**：v1 在表格里以脚注形式提示"高 NI ≠ 安全"；v2 升为第 4 条使用原则，并强调"越适应旧法则的主体，规则切换期越危险"。
- **分形传导**：新增第 6 小节，要求每次分析都向上向下追问"下层死亡是否服务于本主体生存""本主体突破是否触犯上层法则"。

## 3. 方案设计

### 关键决策

| 决策 | 选择 | 理由 |
| ---- | ---- | ---- |
| 是否保留"七步"编号 | 改为"九步核心流程" | 新增"定主体与尺度""设计分形守破"两步，把"先定可死亡边界"前置成流程节点 |
| 守 / 破 是否互斥 | 改为分形并行 | 与宪章"分形自相似"一致；同一主体在不同层同时守、缓、破 |
| 是否保留应用场景示例 | 删除 | 示例容易被当作模板套用，掩盖"先列后果"的强制要求 |
| 输出模板形态 | 从单表改为八段 markdown | 强制把"已观测后果""反推天道""触发信号"独立成段，避免被压缩进一格 |
| 主体层级命名 | 个体 / 组织 / 生态 | 物理尺度（微 / 中 / 宏）会误导跨尺度分析；新命名按"会生存、会交易、会死亡、会进化"的角色划分 |
| 是否新增"使用边界" | 新增第六节 | 明确"不预言、不把宏观叙事当天道、不默认高位安全"，把指南的反预测立场写进规则本身 |

### v2 章节骨架

```
一、使用原则（5 条）
   1. 不预测，只感知后果
   2. 区分事实、推断、猜测
   3. 主体决定一切
   4. 高生态位不等于安全
   5. 死亡是信息

二、核心流程（9 步）
   定主体与尺度 → 列后果 → 反推 N → 拆 EC → 拆 R（显/隐/技）
   → 观 T → 定 NI → 判阶段 → 设计分形守破

三、进化阶段判断（5 阶段，措辞贴近"成败筛选"语言）

四、分形守破策略
   核心功能 / 缓冲层 / 探针层 / 可死亡边界 / 死亡反馈 / 分形传导

五、输出模板（八段 markdown）

六、使用边界（5 条反预测约束）
```

### 与宪章的对应关系

- 第一节原则对应宪章第二条（天道不可观）、第十条（NI ≠ 安全）。
- 第三节阶段模型沿用宪章第十三条五阶段，但把"成败筛选"扩写为"旧高位最危险 + 死亡密集发生 + 死亡是新法则前的主要信息源"。
- 第四节"分形守破"是把宪章第十二条（常规进化 / 突破性进化）与第十五条（分形自相似）合成一个可操作的三层结构。
